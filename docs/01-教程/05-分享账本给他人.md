把账本以**只读授权**的方式共享给家人或伴侣：不用再为「钱花去哪了」反复核对，用手机就能一起理清每一笔开支。本教程带您和家人零门槛走通这条最短路径。

## 您将完成什么与前提

完成本教程后，您可以：

- 创建一个只分享给这一位对方的访问令牌（*以下简称"令牌"*）
- 让对方在手机 App 上把它加成**共享账本**
- 让对方在 Copilot 里问出第一个共享账本问题，并看到回答标注来源

> **前提**：您在平台上**已有一份账本**。若还没有，请先跟随 [快速入门](https://trans.dhr2333.cn/docs/%E6%95%99%E7%A8%8B/quick-start) 上传并解析账单；若您的账本通过 Git 管理，请先按 [配置 Git 同步](https://trans.dhr2333.cn/docs/%E6%93%8D%E4%BD%9C%E6%8C%87%E5%8D%97/git-sync) 让平台能看到它。
>
> 目前仅支持 Android，暂不支持 iOS 系统。

⏱️ 预计耗时：10 分钟（含对方操作）。

## 逐步操作

### 创建分享用的令牌

1. 打开 **个人设置 → 访问令牌**。
2. 点击 **「新建令牌」**，填写：
	- **用途**：如 `共享给老婆`（最多 64 字）
	- **有效期**：1~3650 天，留空表示长期有效
3. 点击 **「创建」**，并**立即复制**弹窗中的令牌——明文**仅显示一次**。
4. 把令牌发给对方，并提醒他登录后复制这段文字。

您应看到：

- 访问令牌列表中新增了这条令牌，前缀形如 `bct_xxxxxxxx…`

<details>
<summary>为什么要单独创建一个访问令牌？</summary>

后续只需撤销该令牌即可收回权限，完全不影响 [接入 AI 客户端](https://trans.dhr2333.cn/docs/%E6%93%8D%E4%BD%9C%E6%8C%87%E5%8D%97/connect-ai-client) 等其他令牌的正常使用。

访问令牌等同于账户凭证，请不要发到公开场合。

</details>

### 让对方在手机上添加共享账本

1. 从 [GitHub Releases](https://github.com/dhr2333/Beancount-Trans-Mobile/releases) 下载 APK 安装（*允许安装未知来源的应用*）。
2. 打开 App，用**手机号验证码**登录。
3. 复制收到的 `bct_xxxxxxxx…` 令牌，再打开（或切回）App——弹出 **「发现共享账本令牌」**，点 **「添加」**。

您应看到：

- 进入 **「我的 → 共享账本」**，列表里出现这条共享账本（来源用户 + 「有效」）

<details>
<summary>没有自动弹出提示怎么办？别名有什么用？</summary>

手动添加：**我的 → 共享账本 → 添加共享账本**，粘贴令牌提交。

**别名**可以留空，也可以填多个。在 Copilot 里点名任意一个别名就能直接问这个账本的账，例如「老公上个月花了多少」。

</details>

### 问出第一个共享账本问题

让对方在 App 的 Copilot 里提问，例如「总共还有多少钱？」：

- Copilot **默认先看对方自己的账本**；对方没有账本、或他自己的账本里查不到时，才会来查您的这份共享账本。
- 提问里点名别名时（如「老公上个月花了多少」），直接查那个账本。

她应看到：

- 回答中的数字标注了**来自哪个账本**（如「来源：老公的账本」）
- 展开 **「查看查询详情」** 能看到本次执行的 BQL 与结果预览

> 注意：想让 Copilot 把两份账本合起来算总数，请明确说「一共 / 总共」；否则它会分别呈现，不会跨账本相加。

## 分享出去之后

- 对方拿到的只有**只读**访问：可以查询、分析，但**不能改动**您的账本。
- **收回访问 = 撤销该令牌**（「个人设置 → 访问令牌」），对方的访问**立即**失效；令牌**过期**、或您的**账号停用**，这份共享会失效（对方的列表里显示「已失效」）。
