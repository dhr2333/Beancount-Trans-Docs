## 术语

| 术语 | 定义 |
| :--- | :--- |
| 账本 | 以 Beancount 文本（`.bean`）承载的复式记账数据集合；平台写入用户 `Assets` 目录下主文件与子文件。（同义：Ledger） |
| 解析 | 将上传的原始账单转为账本可消费的记录的过程。 |
| 映射 | 把账单里的文字（交易对方、商品说明）匹配到目标账户的规则；口语说的「支出分类」由「账户 + 关键字映射」共同实现。 |
| 账户 | Beancount 账户路径（如 `Expenses:Food`），表示资金分类。 |
| 标签 | Beancount 行内的标记（如 `#Project/A`），用于跨账户的临时归类或项目管理；与账户的分工见 [账户 vs 标签](https://trans.dhr2333.cn/docs/%E8%A7%A3%E9%87%8A/account-vs-tag)。 |
| Fava | 平台内置的 Beancount 报表界面，菜单路径为 **「财务报表 → Fava 专业报表」**；文档中出现的旧称「平台账本」指同一处。 |
| 共享账本 | 他人以只读方式分享给你并绑定到你账号下的账本；「分享」指授权这一动作本身。 |
| 访问令牌 | 形如 `bct_…` 的只读凭证，供 MCP 客户端等外部程序访问账本；见 [接入 AI 客户端](https://trans.dhr2333.cn/docs/%E6%93%8D%E4%BD%9C%E6%8C%87%E5%8D%97/connect-ai-client)。 |
| Copilot | 平台内置的 AI 账本助手（文档中亦称「账本助手」）：用自然语言问账、复盘，并把一句话记成待审核条目；只读查询，不直接改账。 |
| 自托管 | 用 Docker Compose 把整套平台部署在你自己的服务器上；见 [自托管](https://trans.dhr2333.cn/docs/developer/self-host)。 |

部分术语的展开说明见：[核心概念](https://trans.dhr2333.cn/docs/%E5%BD%92%E6%A1%A3/core-concepts)。
