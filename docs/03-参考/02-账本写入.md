不同来源的条目确认后，写入的账本文件与方式不同：

| 来源 | 确认后写入 | 写入方式 |
| :--- | :--- | :--- |
| Copilot / 解析首页 | `trans/collect.bean` | 追加 |
| 对账 | `trans/reconciliation.bean` | 追加（由对账流程维护） |
| 账单文件解析 | `trans/{账单名}.bean` | 覆盖 |

## 通用规则

- 条目确认前先进入**暂存区与统一审核队列**，审核截止时间为 **24 小时**。
- 到期仍未处理：系统每小时检查一次，到期的待办会**自动写入**。
- 写入前都会做 Beancount 语法校验；校验不通过则整体不写入。

> Git 用户在 **「Git 同步 → 提交到账本」** 后，`trans/` 中的条目会按交易日期归入仓库根 `{年}/{月}.bean` 并进入 Git 历史。
