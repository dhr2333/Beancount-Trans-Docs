一句话记账时，**哪些必须说、哪些可以省**、**什么时候会进入洞察模式**，以及**共享账本如何参与查询**；操作步骤见教程 [Copilot 快速上手](https://trans.dhr2333.cn/docs/%E6%95%99%E7%A8%8B/copilot)。

## 一句话能记成什么

把默认值交给模型，越省越短：

- **极简**：描述、金额、双向账户，如「早餐皮蛋瘦肉粥 3 元微信支付」。
- **标准**：再补上你想指定的日期、商家、标签或币种。

### 你要说的

| 字段 | 你要说的 | 省了会怎样 |
| :--- | :--- | :--- |
| 金额 | **要说** | / |
| 描述 | **要说** | / |
| 双向账户（支出 / 收入） | 说清渠道即可，如「微信支付」 | 类别账户按描述自动匹配 |
| 双向账户（转账） | 要说清**转出**与**转入** | / |
| 类型 | 不用单独说 | 按句意判定：花了 / 收到 / 转账 |
| 日期 | / | 默认当天 |
| 商家 / 对方 | / | 根据描述并结合已有账本获取 |
| 标签 | / | 默认不加标签 |
| 币种 | / | 默认账本币种（`CNY`） |

### 你需要知道的限制

- 说到的**账户与标签必须已在你的账本中启用**；账户或金额不确定时，模型会先向你确认，不会编造。
- 转账的转出与转入必须是**两个不同的资产账户**。
- 条目里的时间、状态由系统生成（状态固定为 `Copilot - 已记录`）；这些元数据是否写入条目，由 **「输出配置」** 决定。

## 什么时候会进入洞察模式

没有开关，看你的**最新一条提问**：

- 意图是「总结 / 分析 / 洞察 / 趋势 / 报告 / 帮我看看」这类，就会进入。
- 只问具体数字（「花了多少」「余额」「有哪些」）不会进入。

进入后：先跨期对比（按月），再从对方、描述、标签、关联交易、明细元数据等维度追溯 1~2 条线索，结论先行。

## 共享账本

绑定他人分享给你的账本后，可在同一对话内同时分析**个人账本与共享账本**；提问时指定账本**别名**，就能直接查询对应账本。**即使你还没有个人账本，只要绑定了可用的共享账本，也能正常发起对话。**

所有绑定的共享账本自动纳入查询范围，系统会按以下优先级确定查询目标：

| 情形 | 查询目标 |
| :--- | :--- |
| 默认情况 | 个人账本 |
| 个人账本不存在，或个人账本中无匹配查询结果 | 相关的共享账本 |
| 提问中明确指定了账本别名，或要求跨账本对比、统计合计 | 直接查询指定的共享账本（或执行跨账本查询） |

### 你需要知道的限制

- **仅在你明确要求时才会执行跨账本合计**（例如提问中出现「一共」「总共」）；合计时会说明统计口径，并提示个人与共享账本之间的往来转账可能存在重复统计的情况。
- 所有返回的数值都会标注**所属的账本来源**。
- 共享账本的查询结果**不支持 Fava 深链跳转**；「打开本次查询」功能仅对个人账本的查询结果有效。
- 共享账本为**只读权限**，无法通过 Copilot 写入任何新记录。
