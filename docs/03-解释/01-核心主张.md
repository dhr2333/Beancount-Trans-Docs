# 核心主张

**复盘需要清晰的账；清晰不需要每天打卡。**

复盘的前提是账清晰——能核对、能追问、能支撑决策。清晰不靠每天打卡——平时只留凭证，结账日再处理。

## 目的

**看清财务状况，支撑生活中各类与钱相关的决策。**

## 我们相信什么

- **个人账应该像公司账一样运转：平时只留凭证，结账日再处理。**
- **复盘的前提是账清晰。**
- **记账的价值分两层：行为干预，与决策支持；我们服务的是第二层。**
- **复盘要的是能追问的数据，不是月末看一眼余额。**

## 方法

**凭证 → 可审计账本 → 决策前分析**

**AI 不创造数字：** 分类时辅助选择账户；分析时调用查询（如 BQL）解读已有数据。

## Beancount-Trans

**Beancount-Trans 做的，是降低「凭证 → 清晰账本」的成本，让严肃生活者走得通，让复盘发生。**

主读者是严肃生活者（含尚未使用 Beancount 的人）；已有 Beancount 用户是转化最快的子集，不是唯一受众。
